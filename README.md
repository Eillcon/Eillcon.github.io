# Personal Website

## Overview

This repository contains the source code for my personal website, which I use to host my CV, engineering projects, and academic notes. The website acts as a central portfolio to showcase my skills, experience, and technical interests as a Mechanical Engineering student.

The site is designed to be clear, lightweight, and easy to navigate, with a focus on presenting technical content in a professional and accessible way.

## Website Sections

### Home

* Brief introduction and overview of who I am
* Links to key sections of the site

### CV

* Online version of my curriculum vitae
* Summary of education, skills, and experience
* Designed to be easily readable by both recruiters and engineers

### Projects

* Detailed write-ups of engineering and software projects
* Focus on design decisions, methods, and results
* Includes projects spanning mechanical design, embedded programming, and analysis

### Lecture Notes

* Organised academic notes from my Mechanical Engineering degree
* Used as both a personal reference and a demonstration of technical understanding

## Purpose

The primary goals of this website are to:

* Provide a single place to view my CV and portfolio
* Present projects in more depth than a traditional CV allows
* Demonstrate technical communication skills
* Act as a living document that evolves throughout my degree and career

## Technologies Used

* HTML and CSS
* Static site generation
* GitHub Pages for hosting

## Design Philosophy

* Simple, minimal layout
* Dark, modern theme optimised for readability
* Content-first approach, prioritising clarity over visual complexity
* Responsive design for desktop and mobile viewing
